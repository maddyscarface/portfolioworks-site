## Cold-call script (PM / owner)
**Opener (permission):** "Hi {{first}}, it's {{sender}} with PortfolioWorks—I know I'm calling out of the blue. Do you have 30 seconds for me to tell you why I called, and you can tell me if it's relevant?"
**Reason:** "We're a Boston-area contractor that handles rental turnovers and renovations as one managed scope for owners and property managers. {{segment_line}}"
**Question:** "How are you handling turns today—one go-to contractor, or a different trade for each piece?"
- *"We have a guy."* → "Good—most do. Where does it break down: response time, small jobs, or the punch list?" → offer pilot for overflow.
- *"Send me info."* → "Happy to. So I send the right thing—roughly how many units, and which towns?" → book call or send one-pager + calendar.
- *"No budget / not now."* → "Understood. When do your turns peak—summer, September 1?" → set follow-up task for 60 days before peak.
- *"Not interested."* → "Thanks for the straight answer. Mind if I check back in six months?" → DNC if no.
**Close:** "Would it make sense to price one upcoming unit as a pilot? If we don't earn the next one, you've lost nothing."
